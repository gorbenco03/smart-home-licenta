\title{Sistem Smart Home Local-First cu Detecția Anomaliilor Comportamentale prin Învățare Automată pe Edge}
\author{Vidac Denisa}
\date{2026}

\maketitle

% ── Rezumat (RO) ─────────────────────────────────────────────────────
\renewcommand{\abstractname}{Rezumat}
\begin{abstract}
\noindent
Lucrarea prezintă proiectarea și implementarea unui sistem \textit{smart home}
\textit{local-first}, care funcționează integral în rețeaua locală a locuinței,
fără dependență de servicii cloud. Sistemul este organizat pe cinci straturi:
senzori și actuatori, un nod ESP32 cu firmware Arduino, un \gls{rpi} care găzduiește
brokerul \gls{mqtt} \textit{Mosquitto}, o bază de date PostgreSQL/TimescaleDB, un
API NestJS și o aplicație mobilă React~Native. Nodul interior achiziționează
temperatura și umiditatea (două senzoare \gls{dht}11), nivelul de gaz (MQ-2) și
luminozitatea (două \gls{ldr}), și comandă trei \gls{led}-uri, un ventilator, un
servomotor și un buzzer; o cameră ESP32-CAM cu senzor \gls{pir} acoperă exteriorul.
Contribuția principală o reprezintă un modul de \textbf{detecție de anomalii
comportamentale} bazat pe algoritmul \gls{if} (\textit{Isolation Forest}), antrenat
și executat \textbf{local}, pe Raspberry Pi, care învață tiparele normale ale
locuinței și semnalează abaterile fără reguli prestabilite. Lucrarea descrie
arhitectura, implementarea prototipului și metodologia de evaluare, evidențiind
avantajele de confidențialitate, cost și autonomie ale abordării locale.

\medskip\noindent\textbf{Cuvinte-cheie:} smart home, Internet of Things, local-first,
detecție de anomalii, Isolation Forest, edge computing, ESP32, MQTT, Raspberry Pi.
\end{abstract}

% ── Abstract (EN) ────────────────────────────────────────────────────
\renewcommand{\abstractname}{Abstract}
\begin{abstract}
\noindent
This thesis presents the design and implementation of a \textit{local-first}
smart home system that operates entirely within the home's local network, with no
dependency on cloud services. The system is organized in five layers: sensors and
actuators, an ESP32 node running Arduino firmware, a Raspberry~Pi hosting the
\textit{Mosquitto} \gls{mqtt} broker, a PostgreSQL/TimescaleDB database, a NestJS
API and a React~Native mobile application. The indoor node acquires temperature and
humidity (two \gls{dht}11 sensors), gas level (MQ-2) and illumination (two
\gls{ldr}s), and drives three \gls{led}s, a fan, a servo motor and a buzzer; an
ESP32-CAM with a \gls{pir} sensor covers the outdoor area. The main contribution is
a \textbf{behavioural anomaly detection} module based on the \gls{if}
(\textit{Isolation Forest}) algorithm, trained and executed \textbf{locally} on the
Raspberry~Pi, which learns the household's normal patterns and flags deviations
without predefined rules. The thesis describes the architecture, the prototype
implementation and the evaluation methodology, highlighting the privacy, cost and
autonomy benefits of the local approach.

\medskip\noindent\textbf{Keywords:} smart home, Internet of Things, local-first,
anomaly detection, Isolation Forest, edge computing, ESP32, MQTT, Raspberry Pi.
\end{abstract}
